# What I've been doing (the agent's raw material)

Add a line or two whenever something happens: a site visit, an install, a meeting, a lesson
learned, a stat from a project, an event you went to. Rough notes are fine, the agent turns them
into polished posts. Newest at the top. Mark anything confidential with `(private)` and it will
only be used in general terms.

You can also send a note from your phone: GitHub app → Actions → "LinkedIn – daily post" →
Run workflow → fill in "What did you do today?".

Format: `- YYYY-MM-DD: what happened`
